How To Read This View
ACARSAircraft data messages. These often carry position reports, ATIS, weather, maintenance, or operational updates.
VDL2The radio link carrying ACARS and other datalink traffic. A VDL2 badge means the message was heard on the VHF data link itself.
XIDVDL2 link negotiation. Usually not an operational airline message. It is mostly useful when debugging the air-ground data link.
OOOIOut / Off / On / In. Airline movement milestones: leaves gate, takes off, lands, arrives at gate.
ATISAutomatic Terminal Information Service. Airport weather and runway information distributed as text or datalink.
SRC / DSTRadio-link addresses on VDL2. These are network IDs, not aircraft tail numbers or airport names.
Msg # / Block / AckDatalink sequencing and delivery bookkeeping. Useful for protocol analysis, but not usually the main operator takeaway.
dBFSSignal level. Less negative numbers mean a stronger received signal.
